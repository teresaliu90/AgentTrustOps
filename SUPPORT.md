# Support

- Reproducible defects: use the bug-report issue template.
- Integration and design-partner requests: use the adopter report template.
- Security vulnerabilities: follow `SECURITY.md`; do not open a public issue.
- Usage questions: open a [GitHub Discussion](https://github.com/teresaliu90/AgentTrustOps/discussions), or a scoped issue with fictional/redacted data.

This community project currently has no paid support SLA. The best-effort response target is seven
days for ordinary issues. Private vulnerability reports follow the process in `SECURITY.md`; no
fixed security-response SLA is claimed.
