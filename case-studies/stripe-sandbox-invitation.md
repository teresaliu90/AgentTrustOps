# Stripe Sandbox evaluator invitation

## English

> I maintain AgentTrustOps, an Apache-2.0 control plane that prevents duplicate AI-agent side
> effects and reconciles uncertain provider outcomes. Would you independently run a 15–30 minute
> Stripe Sandbox evaluation using your own test account? It uses no real money or customer data and
> refuses live keys. Please try the README without coaching first, then share the generated redacted
> result and your biggest blocker. You may be named, anonymous, or private-only. This will be
> reported as a Sandbox evaluation—not production adoption.

Send the evaluator only the public repository and
