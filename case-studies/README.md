# Case-study evidence policy

This directory accepts only consented, reproducible reports. Sandbox evaluation, design-partner
pilot, and production adoption are distinct evidence levels and must not be relabeled.

For the first external report, run `examples/stripe_sandbox/run_evaluation.py`, complete its
generated `report.md`, remove the private SQLite ledger, and submit the reviewed evidence through a
pull request or the adopter issue form. Never include credentials, personal data, real payment
details, employer systems, or customer information.

The maintainer records assistance, evaluator relationship, version/commit, environment, outcome,
blockers, and visibility consent. Stars, downloads, maintainer demos, and synthetic CI do not count
as external adoption.
