# Adopters

This file lists only organizations or maintainers who have explicitly consented to being named. There are no verified public production adopters yet; repository stars, clones, and the maintainer's own test environment are not presented as adoption.

If you run AgentTrustOps in a pilot or production workflow, open a **Design partner / adopter report** issue. You can choose one of three evidence levels:

1. Named adopter with a public link and a short use case.
2. Anonymous verified adopter, validated privately by the maintainer and reported only as an aggregate count.
3. Design-partner pilot with a reproducible synthetic scenario and no production data.

An adopter entry must record the version, backend, integration, approximate run volume band, and whether the deployment is pilot or production. No customer names, metrics, or logos are added without written consent.
